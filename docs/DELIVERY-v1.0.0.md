# v1.0.0 交付说明

本轮提交说明：**v1.0.0**。承接 2026-10-27 施工计划的剩余工程可靠性与验收工作。应用版本保留 `0.5.0`，Tauri 阻塞修复在独立试验分支交付。

## 主施工内容

1. Workflow 使用耐久写入，独立保存成功文本与音频回执；恢复按请求哈希和工程采纳记录对账，并排空完成态尾部保存与关闭期间已接受的请求。
2. CLI、桌面、浏览器及默认应用服务共用目录所有权协议；外部工程根目录也受保护，退出时持锁等待自有工作排空。
3. Replicate 官方模型采用 owner/name 两段路径，社区模型增加指定版本请求；默认任务 ID 保持整体编码。
4. 模型中心增加纯本地文本费用情景试算；完善单价、币种、用量缺失与未知费用账本语义。
5. 新增三平台原生与媒体验收流水线，分别记录最终搬迁包与源服务验证；系统 sandbox/钥匙环缺失、超时或部分未检查均不能记为通过；补齐 Windows 浏览器探测、原生截图超时和 Linux 自有钥匙环进程的有界退出。

6. 预览每次版本切换使用独立窗口上下文，布局阶段先重置状态，当前成功帧清除旧错误；三项真实 React/Chromium 顺序回归在修前失败、修后通过。

7. 场景写入实际文字与样式后补布局/字体就绪屏障，PNG哈希仍严格核对；不一致时输出有界像素统计用于定位。

搬迁包验收另补本次任务身份与版本屏障、播放器实际就绪等待及固定字段诊断，旧任务不能冒充本次结果，失败任务不会自动重试。

详细施工和验收边界见 [剩余施工计划](REMAINING-PLAN-2026-10-28.md)。真实供应商、真实费用、干净机器安装、签名公证与正式 Tauri 迁移按各自条件独立验收。
